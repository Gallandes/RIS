## Что делает район
Городской SOC собирает журналы всех районов, хранит их так, чтобы их нельзя было незаметно удалить или подменить, ищет признаки атак и открывает инциденты для районов. Для другой команды: присылайте журналы в формате Р4 и подписывайтесь на `city.soc.incident.opened.v1` — так вы узнаете, что на вас напали.

## Как запустить
Нужны Docker и Docker Compose (см. ЛР0).

```bash
cp .env.example .env        # если .env ещё нет; задайте пароль
docker compose up --build -d
docker compose ps
curl -s http://127.0.0.1:8080/health          # → {"status": "ok"}
curl -s http://127.0.0.1:8080/api/v1/info
docker compose logs -f api                    # журнал в формате JSON Lines
docker compose down                           # остановить (данные базы сохранятся)
```

## Как устроен репозиторий
| Путь | Что там |
|---|---|
| `compose.yaml` | весь район: сервисы, сети, тома |
| `services/api/` | сервис-заглушка: `/health`, `/api/v1/info`, журнал JSON — замените своим кодом |
| `contracts/openapi.yaml` | описание HTTP API (Р6) |
| `contracts/events.md` | события, которые район публикует и потребляет (Р5) |
| `docs/architecture.md` | назначение, политика безопасности, DFD, границы доверия |
| `docs/threat-model.md` | модель угроз (v0 — неделя 2, v1 — неделя 6) |
| `docs/access-matrix.md` | матрица доступа (неделя 4) |
| `docs/recovery.md` | восстановление с нуля (неделя 5) |
| `docs/llm-log.md` | журнал использования LLM |
| `l1/` | лабораторная Л1: ответы моделей, проверка, сравнение |
| `scripts/pack.sh` | упаковка для сдачи: ZIP + git bundle |
